## Create Virtual Env

```shell
python -m venv venv
```

## Activate Virtual Env

```shell
source venv/Scripts/activate
```

## Deactivate Virtual Env

```shell
deactivate
```

## Selecting Interpreter

Setelah melakukan instalasi untuk virtual env, harus memilih interpreter dari venv agar seluruh kode berjalan dengan lancar
