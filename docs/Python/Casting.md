Casting adalah proses yang digunakan untuk mengubah tipe data dari variable atau kedalam tipe data lain

## int()

`int()` adalah method yang digunakan untuk mengubah tipe data variable atau value menjadi tipe data int

```py
x = int(1)   # x will be 1  
y = int(2.8) # y will be 2  
z = int("3") # z will be 3
```

## float()

`float()` adalah method yang digunakan untuk mengubah tipe data variable atau value menjadi tipe data float

```py
x = float(1)     # x will be 1.0  
y = float(2.8)   # y will be 2.8  
z = float("3")   # z will be 3.0  
w = float("4.2") # w will be 4.2
```

## str()

`str()` adalah method yang digunakan untuk mengubah tipe data variable atau value menjadi tipe data str

```py
x = str("s1") # x will be 's1'  
y = str(2)    # y will be '2'  
z = str(3.0)  # z will be '3.0'
```
