Pada return didalam function dapat melakukan return terhadap beberapa hal yaitu sebagai berikut

## Return Value

Berikut adalah cara melakukan return berupa value

```py
def get_greeting():  
  return "Hello from a function"  
  
print(get_greeting())
```

## Return Variable

Berikut adalah cara melakukan return berupa variable

```py
def get_greeting():
    message = "Hello from a function"
    return message

print(get_greeting())
```
