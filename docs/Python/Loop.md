## For In

Berikut adalah contoh penggunaan loop for in

```py
fruits = ["apple", "banana", "cherry"]  
for x in fruits:  
  print(x)
```

## For In Range

Berikut adalah contoh penggunaan loop for in range

```py
for i in range(10):  
  print(i)
```

## While

Berikut adalah contoh penggunaan loop while

```py
i = 1  
while i < 6:  
  print(i)  
  i += 1
```
