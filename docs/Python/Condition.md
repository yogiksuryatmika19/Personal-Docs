## If

Berikut adalah penggunaan dari perkondisian if

```py
a = 33  
b = 200  
if b > a:  
  print("b is greater than a")
```

## If Else

Berikut adalah penggunaan dari perkondisian if else

```py
a = 200  
b = 33  
if b > a:  
  print("b is greater than a")  
else:  
  print("b is not greater than a")
```

## Elif

Berikut adalah penggunaan dari perkondisian elif

```py
score = 75  
  
if score >= 90:  
  print("Grade: A")  
elif score >= 80:  
  print("Grade: B")  
elif score >= 70:  
  print("Grade: C")  
elif score >= 60:  
  print("Grade: D")
```

## Ternary

Berikut adalah penggunaan dari perkondisian ternary

```py
a = 5  
b = 2  
if a > b: print("a is greater than b")
```

## Match

Berikut adalah penggunaan dari perkondisian match

```py
day = 4  
match day:  
  case 1:  
    print("Monday")  
  case 2:  
    print("Tuesday")  
  case 3:  
    print("Wednesday")  
  case 4:  
    print("Thursday")  
  case 5:  
    print("Friday")  
  case 6:  
    print("Saturday")  
  case 7:  
    print("Sunday")
```
