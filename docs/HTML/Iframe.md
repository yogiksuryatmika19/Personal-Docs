## Iframe

`<iframe>` adalah element yang digunakan untuk menampilkan halaman web lain melalui jendela kecil

## Iframe Atribut

Berikut adalah atribut yang ada pada `<iframe>`

| Atribut Iframe | Keterangan                     |
| -------------- | ------------------------------ |
| `src`          | URL link untuk website lain    |
| `title`        | Tooltip ketika iframe di hover |

### src

`src` adalah atribut untuk mengatur URL dari website lain yang diinginkan pada iframe

```html
src="demo_iframe.htm"
```

### title

`title` adalah atribut untuk mengatur tooltip pada iframe ketika dihover

```html
title="Iframe Example"
```

## Example

Berikut adalah implementasi dari penggunaan tag / element `<iframe>`

```html
<iframe src="demo_iframe.htm" title="Iframe Example"></iframe>
```
