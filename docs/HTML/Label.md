## Label

`<label>` adalah element dari form yang digunakan berpasangan dengan id sebuah input

## Label Atribut

Berikut adalah atribut yang ada pada `<label>`

| Label Atribut | Keterangan                                              |
| ------------- | ------------------------------------------------------- |
| `for`         | Penanda bahwa label merupakan label dari input tertentu |

## Example

Berikut adalah implementasi dari penggunaan element `<label>`

```html
<label for="fname">First name:</label>  
<input type="text" id="fname" name="fname">
```
