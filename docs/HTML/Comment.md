## Single Line Comment

Berikut adalah cara untuk membuat komentar satu baris pada HTML

```html
<!-- Ini adalah komentar satu baris -->

<p>Selamat datang di website saya.</p>
```

##  Multi Line Comment

Berikut adalah cara untuk membuat komentar banyak baris pada HTML

```html
<!--
    Ini adalah komentar multi-line.
    Bisa digunakan untuk menjelaskan bagian kode
    atau memberi catatan panjang.
-->
<p>Selamat datang di website saya.</p>
```
