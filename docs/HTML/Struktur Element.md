## Struktur Element

Berikut adalah penyusun dari element HTML

| Struktur Element |
| ---------------- |
| Tag Pembuka      |
| Content          |
| Tag Penutup      |

## Example

Misal pada kode HTML berikut ini

```html
<h1>Chapter 1</h1>
<p>ini adalah paragraf dari chapter 1...<p>
```

Berikut adalah pembagian dari struktur element diatas

| Tag Pembuka | Content                               | Tag Penutup |
| ----------- | ------------------------------------- | ----------- |
| `<h1>`      | Chapter 1                             | `</h1>`     |
| `<p>`       | ini adalah paragraf dari chapter 1... | `</p>`      |
