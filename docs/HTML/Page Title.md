## Page Title

Page title dapat diubah dengan mengubah `<title>` pada bagian `<head>` dari file HTML

## Example

Berikut adalah contoh implementasi proses mengubah `<title>`

```html
	<!DOCTYPE html>
	<html>
	<head>
	    <title>First Page</title>
	</head>
	<body>
	    <h1>Halo World!</h1>
	    <p>Ini adalah paragraf pertama saya.</p>
	</body>
	</html>
```
