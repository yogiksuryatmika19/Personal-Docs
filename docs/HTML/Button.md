## Button

`<button>` adalah element yang digunakan untuk melakukan suatu task tertentu ketika diklik

## Button Atribut

Berikut adalah atribut yang terdapat pada element `<button>`

| Button Atribut | Keterangan                  |
| -------------- | --------------------------- |
| `type`         | Mendefinisikan jenis button |

### type

Berikut adalah value yang ada pada atribut `type`

| Value    | Keterangan                                                      |
| -------- | --------------------------------------------------------------- |
| `button` | Ketika diklik tidak melakukan apa-apa                           |
| `submit` | Ketika diklik melakukan submit form                             |
| `reset`  | Ketika diklik melakukan reset untuk input yang sudah dimasukkan |

## Example

Berikut adalah contoh dari implementasi element `<button>`

```html
<button type="submit">Submit</button>
```
