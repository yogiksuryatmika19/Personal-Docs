## Head

Berikut adalah bagian `<head>` dari file HTML

```html hl_lines="3-5"
	<!DOCTYPE html>
	<html>
	<head>
	    <title>First Page</title>
	</head>
	<body>
	    <h1>Halo World!</h1>
	    <p>Ini adalah paragraf pertama saya.</p>
	</body>
	</html>
```
