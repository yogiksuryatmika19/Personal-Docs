List pada HTML terbagi menjadi 2 jenis yaitu sebagai berikut

| List   | Keterangan     |
| ------ | -------------- |
| `<ol>` | Ordered List   |
| `<ul>` | Unordered List |

## Ordered List

Ordered list terdiri dari hal berikut ini

| Ordered List | Keterangan                  |
| ------------ | --------------------------- |
| `<ol>`       | Container dari ordered list |
| `<li>`       | List item                   |
