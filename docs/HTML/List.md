List pada HTML terbagi menjadi 2 jenis yaitu sebagai berikut

| List   | Keterangan     |
| ------ | -------------- |
| `<ol>` | Ordered List   |
| `<ul>` | Unordered List |

## Ordered List

Ordered list adalah list terurut berupa 1, 2, 3, ...

Ordered list terdiri dari hal berikut ini

| Ordered List | Keterangan                  |
| ------------ | --------------------------- |
| `<ol>`       | Container dari ordered list |
| `<li>`       | List item                   |

Berikut adalah contoh implementasi dari ordered list

```html
<ol>
	<li>Coffee</li>
	<li>Tea</li>
	<li>Milk</li>
</ol>
```

## Unordered List

Unordered list adalah list tidak terurut yang berupa bullet

Unordered list terdiri dari hal berikut ini

| Unordered List | Keterangan                    |
| -------------- | ----------------------------- |
| `<ul>`         | Container dari unordered list |
| `<li>`         | List item                     |

Berikut adalah contoh implementasi dari unordered list

```html
<ul>
	<li>Coffee</li>
	<li>Tea</li>
	<li>Milk</li>
</ul>
```
