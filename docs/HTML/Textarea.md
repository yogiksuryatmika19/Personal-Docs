## Textarea

`<textarea>` adalah element dari form yang digunakan untuk menerima input text panjang

## Textarea Atribut

Berikut adalah atribut dari `<textarea>`

| Atribut Textarea | Keterangan                                           |
| ---------------- | ---------------------------------------------------- |
| `id`             | Penanda unik untuk element textarea                  |
| `name`           | Variable yang bertugas menangkap input dari textarea |

## Example

Berikut adalah implementasi dari element `<textarea>`

```html
<textarea name="message" rows="10" cols="30">  
The cat was playing in the garden.  
</textarea>
```
