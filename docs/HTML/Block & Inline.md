## Block

- Element block akan selalu membuat baris baru ketika dibuat
- Element block memiliki width sebesar dari element parent nya

## Inline

- Element inline adalah element yang tidak akan membuat baris baru setelah dibuat
- Element inline akan memiliki width sebesar content didalamnya
