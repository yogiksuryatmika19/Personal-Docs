Struktur CSS terdiri dari hal berikut ini

| Struktur CSS |
| ------------ |
| Selector     |
| Property     |
| Value        |

Misal pada contoh kode dibawah ini

```css
p {
  color: red;
  text-align: center;
}
```

Berikut pembagian struktur nya

| Selector | Property                | Value                 |
| -------- | ----------------------- | --------------------- |
| `p`      | `color`<br>`text-align` | `red`<br>`text-align` |
