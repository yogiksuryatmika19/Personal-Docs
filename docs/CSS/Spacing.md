## Text Align

| Value   | Example               |
|---------|-----------------------|
| left    | text-align: left;     |
| right   | text-align: right;    |
| center  | text-align: center;   |
| justify | text-align: justify;  |

## Text Indent

| Value | Example               |
|-------|-----------------------|
| px    | text-indent: 50px;    |
| em    | text-indent: 2em;     |
| %     | text-indent: 10%;     |

## Letter Spacing

| Value | Example                  |
|-------|--------------------------|
| px    | letter-spacing: 3px;     |
| -px   | letter-spacing: -1px;    |
| em    | letter-spacing: 0.1em;   |

## Line Height

| Value   | Example                |
|---------|------------------------|
| normal  | line-height: normal;   |
| number  | line-height: 1.6;      |
| %       | line-height: 80%;      |
| px      | line-height: 24px;     |

## Word Spacing

| Value | Example                |
|-------|------------------------|
| px    | word-spacing: 10px;    |

| em    | word-spacing: 0.2em;   |
