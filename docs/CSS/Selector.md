## Element Selector

```css
p {
  text-align: center;
  color: red;
}
```

## Id Selector

```css
#para1 {
  text-align: center;
  color: red;
}
```

## Class Selector

```css
.center {
  text-align: center;
  color: red;
}
```

## Universal Selector

```css
* {
  text-align: center;
  color: blue;
}
```

## Grouping Selector

```css
h1, h2, p {
  text-align: center;
  color: red;
}
```
