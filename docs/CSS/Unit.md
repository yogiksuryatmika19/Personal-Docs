## Absolute Unit

| Absolute Unit | Keterangan           |
| ------------- | -------------------- |
| `px`          | pixel (ukuran pasti) |

## Relative Unit

| Relative Unit | Keterangan                       |
| ------------- | -------------------------------- |
| `em`          | Relative terhadap parent element |
| `rem`         | Relative terhadap root element   |
| `vw`          | Relative terhadap lebar layar    |
| `vh`          | Relative terhadap tinggi layar   |
| `%`           | Relative terhadap parent element |
