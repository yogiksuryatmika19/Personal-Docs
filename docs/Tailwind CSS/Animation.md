# animation

| Class             | Style (CSS) / Behavior                 |
| ----------------- | -------------------------------------- |
| `animate-none`    | `animation: none;`                     |
| `animate-spin`    | Elemen berputar terus-menerus          |
| `animate-ping`    | Elemen membesar lalu memudar (pulse)   |
| `animate-bounce`  | Elemen memantul naik-turun             |
| `animate-pulse`   | Elemen berubah opacity secara berulang |
| `animate-[value]` | `animation: <custom animation>;`       |
