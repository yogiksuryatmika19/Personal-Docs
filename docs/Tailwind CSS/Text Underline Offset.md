# text-decoration-offset

|Kelas|Deskripsi|
|---|---|
|`underline-offset-0`|Garis sangat dekat dengan teks|
|`underline-offset-1`|Sedikit jarak|
|`underline-offset-2`|Jarak kecil|
|`underline-offset-4`|Jarak sedang|
|`underline-offset-8`|Jarak jauh|
|`underline-offset-auto`|Default dari browser/font|
