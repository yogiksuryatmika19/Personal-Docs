# text-decoration-line

| Kelas          | Deskripsi                    | Contoh Hasil |
| -------------- | ---------------------------- | ------------ |
| `underline`    | Garis bawah teks             | _Hello_      |
| `overline`     | Garis di atas teks           | ‾Hello‾      |
| `line-through` | Coret tengah (strikethrough) | ~~Hello~~    |
| `no-underline` | Menghapus underline          | Hello        |
