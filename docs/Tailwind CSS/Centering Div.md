Untuk melakukan centering terhadap `<div>` container atau terluar dapat menggunakan `m-auto`

| Centering Div Container (Terluar) |
| --------------------------------- |
| `m-auto`                          |

Berikut adalah contoh implementasi dari centering `<div>` terluar

```html
<div class="w-64 h-32 bg-blue-500 text-white m-auto">
  Container di tengah secara horizontal
</div>
```
