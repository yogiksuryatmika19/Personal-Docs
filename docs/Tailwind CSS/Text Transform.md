# text-transform

| Kelas         | Deskripsi                       | Contoh Hasil |
| ------------- | ------------------------------- | ------------ |
| `uppercase`   | Semua huruf jadi kapital        | HELLO WORLD  |
| `lowercase`   | Semua huruf jadi kecil          | hello world  |
| `capitalize`  | Huruf pertama tiap kata kapital | Hello World  |
| `normal-case` | Kembali ke default              | Hello world  |
