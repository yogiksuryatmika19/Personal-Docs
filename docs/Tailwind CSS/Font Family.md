# font-family

| Kelas        | Font Family Default (Tailwind)                                                      | Deskripsi                        |
| ------------ | ----------------------------------------------------------------------------------- | -------------------------------- |
| `font-sans`  | ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif | Sans-serif (default modern UI)   |
| `font-serif` | ui-serif, Georgia, Cambria, "Times New Roman", serif                                | Serif (klasik / formal)          |
| `font-mono`  | ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace                    | Monospace (coding / fixed width) |
