Pada element yang ingin dilakukan centering text dapat menggunakan centering text, dapat menggunakan class berikut ini

> Letakkan class berikut pada element yang text nya ingin di-centering

| Centering Text |
| -------------- |
| `text-center`  |

Berikut adalah impelementasinya

```html
<div class="w-64 bg-gray-200 p-4 text-center">
  <p class="text-blue-600 font-bold">Teks di tengah horizontal</p>
</div>
```
