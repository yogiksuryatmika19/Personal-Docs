# text-decoration-thickness

| Kelas                  | Deskripsi                     |
| ---------------------- | ----------------------------- |
| `decoration-0`         | Tidak terlihat / sangat tipis |
| `decoration-1`         | Sangat tipis (default halus)  |
| `decoration-2`         | Sedikit lebih tebal           |
| `decoration-4`         | Tebal                         |
| `decoration-8`         | Sangat tebal                  |
| `decoration-auto`      | Default browser               |
| `decoration-from-font` | Mengikuti font metrics        |
